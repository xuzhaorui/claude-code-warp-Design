## 功能使用说明

### 1. 出库

1. 进入“出库”页。
2. 扫描货物二维码，或输入/识别对应编号。
3. 选择出库方式：
   - 外销
   - 外借
4. 填写出库数量。
5. 如为外销，填写销售总价。
6. 如为外借，可填写出库备注。
7. 点击提交。

#### 出库校验规则

- 数量必须大于 0。
- 出库数量超过库存时：
  - 页面会显示超库存提示
  - 提交按钮会禁用
- 外销模式下，销售总价必须大于 0 才允许提交。
- 如果销售单价低于成本单价，系统会提示亏损风险，确认后才可继续提交。

### 2. 归还

1. 进入“归还”页。
2. 扫描借出记录对应二维码，或进入对应归还表单。
3. 填写归还数量。
4. 可选填写归还备注。
5. 点击“确认归还”。

#### 归还校验规则

- 数量必须大于 0。
- 归还数量超过在借数量时：
  - 页面会显示超出在借数量提示
  - 提交按钮会禁用
- 无归还权限的账号不可执行该功能。

### 3. 盘点

1. 进入“盘点”页。
2. 扫描货物二维码，或通过图片识别编号。
3. 输入实盘数量。
4. 填写备注后提交。

## 建议测试用例

### 出库

- 正常出库数量小于库存，允许提交
- 出库数量等于库存，允许提交
- 出库数量大于库存，显示警告并禁止提交
- 外销未填写销售总价，禁止提交
- 外销单价低于成本单价，需确认亏损后提交

### 归还

- 归还数量小于在借数量，允许提交
- 归还数量等于在借数量，允许提交
- 归还数量大于在借数量，显示警告并禁止提交

### 盘点

- 正常盘点可提交
- 不同权限账号均可验证盘点功能是否可见、可操作
